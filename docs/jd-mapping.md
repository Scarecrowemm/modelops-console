# JD 对应关系 · AI 模型运营 / AI 网关运营

> 用途：面试时按 JD 逐条对应到项目里的代码、页面和文档，避免“我了解”式空谈。

## 一、工作职责

| JD 原文 | 项目里的对应 | 面试时拿什么证明 |
|---|---|---|
| 1. 模型全生命周期运营：信息跟踪、评估、上下架发布及用户迁移 | `app/lifecycle.py` 状态机 + `app/evaluation.py` + `app/migration.py` + 看板生命周期区 | 演示 v3 从 evaluating → approved → canary 的流转；展示迁移批次表 |
| 2. 监控模型调用、稳定性及成本数据，定期输出运营分析报告 | `app/metrics.py` + `app/reports.py` + 看板 + 日报/周报 | 打开看板；展示 `docs/daily-report-sample.md` |
| 3. 协调技术团队、供应商及业务部门解决模型运营问题，并推动闭环 | `app/incidents.py` + `docs/runbook.md` + `docs/raci.md` + 复盘样例 | 讲 INC-20261028-001 的时间线、根因、行动项与验证 |
| 4. 完善模型运营流程及相关文档，持续优化模型服务质量和使用成本 | `docs/model-cards/` + `docs/migration-plan.md` + `docs/raci.md` + 成本分析 | 展示模型卡、迁移计划、RACI；讲成本下钻方法 |

## 二、任职要求

| JD 原文 | 项目里的对应 | 面试时拿什么证明 |
|---|---|---|
| 1. 了解大模型及 AI 网关的基本原理 | `app/gateway.py`：OpenAI 兼容、路由、限流、fallback、计量 | 讲一次请求的完整链路：鉴权 → 限流 → 路由 → 上游 → 计量 → 账单 |

| 4. AI 平台/模型运营实习经验优先 | 整个项目就是模拟平台的运营工作台 | 用日报、周报、迁移计划当作品集 |

## 三、面试 10 分钟脚本

1. **1 分钟**：平台是什么，规模（3 上游 / 8 模型 / 200 租户 / 1,000 请求回放）。
2. **2 分钟**：打开看板，讲今日成本、成功率、P95、429，以及 3 条告警。
3. **2 分钟**：讲生命周期——v3 为什么从 tracking 走到 canary，门槛是什么。
4. **2 分钟**：讲评估报告——质量/成本/延迟的决策矩阵，为什么推荐某个模型。
5. **2 分钟**：讲迁移——40 个租户分 4 批，回滚条件是什么。
6. **1 分钟**：讲事件闭环——429 风暴的根因、行动项、验证。

## 四、不要夸大的点

- 这是**模拟平台**：3 个 mock 上游、200 个模拟租户、1,000 条回放请求，不是真实业务。
- 质量分是 mock 模拟值；真实使用时替换为 rubric / LLM-as-judge。
- 成本节省数字要带基线，否则说“模拟环境中单位请求成本变化 X%”。
